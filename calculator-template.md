## **BharatCalc Codex Operating Manual** 

## **Mission** 

BharatCalc is a calculator-first SEO business. 

The primary objective is: 

1. Publish calculators quickly. 

2. Maintain a consistent design system. 

3. Maintain high SEO quality. 

4. Never break existing calculators. 

5. Scale to hundreds of calculators. 

## **Core Rules** 

When creating or modifying any calculator: 

- Reuse existing components whenever possible. 

- Never redesign existing layouts. 

- Never introduce new color schemes. 

- Never change global styling unless explicitly requested. 

- Follow the structure of existing calculators. 

- Preserve mobile responsiveness. 

- Keep pages lightweight and fast. 

If an existing component already solves the problem, use it. 

## **Calculator Creation Workflow** 

When a new calculator is requested: 

1. Create calculator page. 

2. Implement calculation logic. 

3. Create SEO metadata. 

4. Create explanation content. 

5. Create FAQ section. 

6. Add related calculators. 

7. Update calculator index. 

8. Update sitemap if applicable. 

9. Add internal links. 

1 

10. Verify responsiveness. 

Do not skip any step. 

## **Design System Rules** 

Every calculator must use: 

- Existing navbar 

- Existing footer 

- Existing typography 

- Existing spacing system 

- Existing color palette 

- Existing button styles 

- Existing card styles 

Do not invent new UI patterns. 

## **Navigation Rules** 

Every calculator must: 

- Link back to homepage through logo. 

- Link to exactly 4 related calculators. 

- Be discoverable from existing calculators. 

- Be included in category navigation if relevant. 

Internal linking is mandatory.

## **SEO Rules** 

Every page must include: 

- Unique title 

- Unique meta description 

- Canonical URL 

- Structured heading hierarchy 

- FAQ schema 

- Breadcrumb schema if available 

Target search intent first. 

Do not keyword stuff. 

Write for humans. 

## **Content Rules** 

Calculator content should include: 

## **What Is It?** 

Simple explanation. 

## **Formula** 

Explain formula in simple words. 

## **Example** 

Show real-world example. 

## **Benefits** 

Explain practical usage. 

3 

## **FAQ** 

Provide at least 5 FAQs. 

Content should be beginner-friendly. 

Avoid unnecessary technical jargon. 

## **Related Calculators Rules** 

Always show exactly 4 related calculators. 

Selection priority: 

1. Same category 

2. Similar use case 

3. Similar audience 

Never show more than 4. 

## **Performance Rules** 

Pages must: 

- Load fast 

- Avoid unnecessary JavaScript 

- Avoid large images 

- Avoid unused dependencies 

- Minimize bundle size 

Performance is a ranking factor. 

## **Code Quality Rules** 

Before finishing: 

- Check calculations. 

- Check edge cases. 

- Check responsiveness. 

- Check TypeScript errors. 

- Check broken links.

- Check imports. 

Do not leave warnings unresolved.
